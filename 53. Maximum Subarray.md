# [53. Maximum Subarray](https://leetcode.com/problems/maximum-subarray/)

```
class Solution {
    public int maxSubArray(int[] nums) {
        int sum=nums[0];
        int maxsum=nums[0];

        for(int i=1;i<nums.length;i++)
        {
            if(sum>=0)
            sum+=nums[i];
            else
            sum=nums[i];
            if(sum>maxsum)
            maxsum=sum;
        }
        return maxsum;
    }
}
```
### Kadane's Algorithm:
> - add the new elements until sum becomes negative.
> - once sum becomes negative then no need to add, because it's already a negative value. so create a new sum(sub array start) with that element.
